# FormCourier CRM

FormCourier CRM connects Contact Form 7 or WPForms to HubSpot CRM or Pipedrive.

## Included features

- Contact Form 7 and WPForms
- HubSpot contact synchronization and Contact + Deal mode
- Pipedrive person with deal or lead synchronization
- Global visual field mapping for every supported form and CRM pair
- Immediate sending during form submission
- CRM connection testing
- Privacy-aware technical logs
- Encrypted credential storage when OpenSSL is available
- English, Russian and Ukrainian interface translations
- Localized offline documentation and standard field-mapping examples

The Lite package does not contain the premium queue, automatic retries, UTM tracking, Telegram notifications, advanced diagnostics, licensing or custom update modules.
